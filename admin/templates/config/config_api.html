如何添加新版本（例如 v4）：
  1. 在"可用的API版本"中添加 v4（例如：v1,v2,v3,v4）
  2. 在 api.php 中添加 v4 版本的路由块
  3. 在 app/Controllers/Front/ 下创建 V4 文件夹和控制器
  4. 在后台启用 v4 版本
