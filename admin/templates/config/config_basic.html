站点状态与维护模式

此区域控制站点对访客的可见性。修改后立即生效，管理员始终可以访问后台。

开启后，普通访客将看到维护提示页面，常用于系统升级或数据迁移。

维护模式开启时显示给访客的提示文字，最多500个字符。

开放：所有人都可以正常访问站点。
关闭站点：非管理员将看到"站点暂停服务"的提示页面。
私密：未登录用户将被重定向至登录页。

站点状态为"关闭"时显示给访客的提示文字，最多500个字符。

站点 Favicon

站点 Favicon 会显示在浏览器标签页、书签、移动端主屏。建议使用 32x32 或 64x64 像素的 PNG/ICO 图片。

支持 ico/png/jpg/gif/svg/webp 格式，大小不超过 1MB。

RSS 订阅

RSS（Really Simple Syndication）让用户可以通过 RSS 阅读器订阅您的站点文章更新。

开启后，访客可以通过站点 /rss 路径订阅您的文章更新。

每次 RSS 请求返回的最新文章数量，建议 10-50 篇。

摘要模式只展示文章开头部分，可引导用户访问站点；全文模式将完整文章内容输出到 RSS 中。

RSS 内容缓存时间，设为 0 表示不缓存，建议 3600（1 小时）。

RSS feed 的语言标识，例如 zh-cn、en-us。
