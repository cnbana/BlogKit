📦 数据库迁移管理

自动比对 install.sql 与当前数据库结构，发现差异后一键同步。 支持 新增表/字段/索引、外键约束同步、配置项种子数据、ENUM 类型变更。

📖 使用说明

第一步：检查版本状态

• 查看页面上方的「当前数据库版本」和「目标版本」

• 如果状态显示为「✅ 最新」，说明数据库已是最新版本

• 如果状态显示为「⚠ 需要升级」，请继续下一步

第二步：预览变更（推荐）

• 点击「🔍 预览变更」按钮

• 系统会分析并显示将要执行的 SQL 语句

• 仔细检查这些变更是否符合预期

第三步：执行迁移

• 确认预览的变更无误后，点击「⚡ 执行迁移」

• 系统会自动执行所有数据库更新操作

• 执行完成后会显示详细报告

第四步：查看结果

• 查看执行报告确认迁移是否成功

• 页面底部会显示最近的迁移历史记录

• 成功后状态会自动更新为「✅ 最新」

⚠️ 注意事项
  • 备份数据：执行迁移前建议先备份数据库，以防万一
  • 先预览再执行：务必先点击「预览变更」检查将要执行的 SQL
  • 安全原则：本系统只做新增操作，不会删除任何表或字段
  • 失败保护：执行出错时不会更新版本号，可以安全重试
  • 查看日志：页面底部的迁移历史可以查看所有操作记录
