数据库迁移

自动比对 install.sql 与当前数据库结构，发现差异后一键同步。只做新增操作，不会删除任何表或字段。

使用说明与注意事项
使用步骤
  1. 检查版本状态：状态为「最新」时无需操作；为「需要升级」时继续下一步
  2. 预览变更：点击「预览变更」，检查将要执行的 SQL 是否符合预期
  3. 执行迁移：确认无误后点击「执行迁移」，完成后查看执行报告
  4. 查看结果：页面底部的历史日志记录所有操作，成功后状态自动更新为「最新」
注意事项
  • 执行迁移前建议先备份数据库
  • 务必先预览再执行；执行出错不会更新版本号，可安全重试
  • 系统只做新增操作，绝不删除任何表、字段或索引
能力说明
  • 新增表/列/索引：检测 install.sql 中缺失的表和字段，自动生成 ALTER TABLE ADD
  • 外键约束同步：自动添加缺失的外键约束，保证数据引用完整性
  • 配置项种子数据：自动插入新增的配置项，不动已有配置
  • ENUM 类型变更：检测枚举列新增取值，自动 MODIFY COLUMN 追加
  • 版本自动识别：从 install.sql 头部注释提取目标版本号，无需手动修改常量
  • 迁移审计日志：每次操作记录到 bk_migration_log 表，可追溯历史变更
